## 共识评分规则：consensus_score
- 1.0：所有助手的核心答案完全一致。
- 0.5：多数助手答案相近或一致，但至少有一个给出了明显不同的答案。
- 0：各助手的答案各不相同，无法形成多数共识。
- null：只有一个回答。
（恰好两个助手时：一致为 1.0，不一致为 0。）

## 输出要求
只输出一个 JSON 对象，不要输出任何其他文字，也不要使用代码块标记：
{{"consensus_score": 1.0, "confidence": "高", "analysis": "…", "final_answer": "…"}}
- consensus_score：按上述规则给出 1.0 / 0.5 / 0 / null
- confidence：只能是 "高"、"中"、"低" 之一
- analysis：按标签（助手 A、B……）给出你的评估，包括与首轮评审的异同（Markdown）
- final_answer：直接回答用户的最终答案（Markdown）
